# 2026-10 — Release 1.4.0: CI/CD estable, login web y versionado por tags

> **Fecha:** 2026-10-16
> **Versión:** 1.4.0 (tag `v1.4.0` en el merge de `develop` → `master`)
> **Alcance:** CI/CD, web publicada, autenticación, i18n, versionado, documentación

---

## Resumen

Primera release desde agosto de 2026. Incluye la estabilización completa de CI/CD y las correcciones derivadas de la revisión del 16 de octubre.

## CI/CD

- **Build de Windows reparado.** Nunca había funcionado: lo ocultaba `continue-on-error`. Causa: `-p:RuntimeIdentifier=win-x64` como propiedad global contaminaba el TFM Android de `ObservApp.Shared` (`UseMonoRuntime=true`) y el restore pedía `Microsoft.NETCore.App.Runtime.Mono.win-x64`, inexistente (NU1102). Ahora se usa `RuntimeIdentifierOverride`, con el bloque correspondiente en `ObservApp.csproj`. El build Release va sin `--no-restore` (necesita runtime packs que el restore Debug no baja). Publish MSIX sin firmar, sin certificado temporal, subido como artefacto.
- **Deploy a Azure Static Web Apps reparado.** Un paso de diagnóstico abortaba el job (SIGPIPE con `pipefail` en `sort | head`). El publish bajó de 267 MB a 43 MB eliminando los temas Syncfusion no usados (la SWA es plan Free, límite 250 MB).
- **GitVersion** exporta `MAJOR`, `MINOR` y `MAJORMINORPATCH`. La versión visible de APK y MSIX sale de GitVersion; `Package.appxmanifest` lleva el marcador `Version="0.0.0.0"` que MAUI rellena.

## Web publicada

- **Login funcional.** La build standalone no recibía `SupabaseUrl` ni `SupabaseAnonKey`; ahora el workflow los escribe desde secretos y falla con mensaje claro si faltan. `AutoConnectRealtime=false` en WASM y MAUI (la app no usa Realtime) elimina el error `Failed to start Websocket client ... net_WebSockets_Scheme`.
- **Sesión.** Restauración automática tras el primer render del layout y en `AuthGuard` antes de redirigir, sin `forceLoad`.
- **Clave Syncfusion** retirada de `wwwroot/appsettings.json`; en desarrollo la sirve `/api/client-config` desde la configuración del host. Pendiente rotarla en el portal de Syncfusion.
- **Lightbox del listado DSO** corregido: el overlay se crea en `document.body`, fuera del componente, así que el CSS aislado no le aplicaba. Reglas movidas al `app.css` global de Shared.

## Otros

- Ruta `/mapa` operativa como alias de la gestión de ubicaciones.
- i18n: los 8 idiomas con las mismas 499 claves (24 claves `Eph_DSO_*` añadidas al árabe; clave huérfana eliminada del italiano).
- **Versionado unificado por tags**: `GitVersion.MsBuild` en local (excluido en CI), workflow en CI, reserva solo sin repo git. Tags válidos: `vX.Y.Z`. Eliminados `v.1.3.4` y `v1.3.3.1`.
- Limpieza de `.slnx`, README y avisos de compilación. Actualización de paquetes NuGet (Extensions 10.0.13, Supabase 8.4.0, Syncfusion 35.1.40).
