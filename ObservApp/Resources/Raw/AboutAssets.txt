Cualquier recurso sin procesar que desee implementar con su aplicación puede ubicarse en este directorio (y subdirectorios). 
La implementación del recurso en su aplicación se gestiona automáticamente mediante la siguiente acción de compilación 
`MauiAsset` dentro de su archivo `.csproj`.

    <MauiAsset Include="Resources\Raw\**" LogicalName="%(RecursiveDir)%(Filename)%(Extension)" />

Estos archivos se implementarán con su paquete y serán accesibles mediante Essentials:

    async Task LoadMauiAsset()
    {
        using var stream = await FileSystem.OpenAppPackageFileAsync("AboutAssets.txt");
        using var reader = new StreamReader(stream);

        var contents = reader.ReadToEnd();
    }
